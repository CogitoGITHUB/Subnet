* The area
# what the area is and what it owes.
# The work mode loads the config live from the source: the file is read
# at the start and looked at again on every turn of the client's own
# loop, so an edit to the file is seen without a restart. The bake makes
# the config into first-class defaults in a generated file, so a baked
# program carries them inside it and needs no user file at startup.
#
# There is NO timer and NO watcher in here: the client asks when its own
# loop turns, and the rebuild is manual — the owner runs the bake when
# they decide, and it says what it did when it is done.
#
# The area is BELOW the client, so it may not require it: the config is
# read from a path and the bake takes a state directory as an argument.

Everything here exists for an AI agent driving =pm=: the skill, the
OpenCode plugin, and the TV channel declarations.

* What lives here

| path | what it is |
|------|------------|
| =agent/skills/aiu-pm/= | the skill file and its examples |
| =agent/opencode-plugin/= | the OpenCode plugin (Node). =npm install= first |
| =agent/tv/= | TV channel declarations (spec and package channels) |

* Where the ecosystem-wide files live
These are NOT in this repository. They govern every project under
=AIU-ECOSYSTEM/=, not just =pm=, so they stay where every project can
find them:

| what | full path |
|------|-----------|
| the binding rules | =AIU-ECOSYSTEM/HARD-RULES.org= |
| agent instructions | =AIU-ECOSYSTEM/AGENTS.md= |
| narration, verbosity, policy, workflow | =AIU-ECOSYSTEM/agents/*.md= |
| the root readme | =AIU-ECOSYSTEM/README.org= |

Read =HARD-RULES.org= before changing anything here. It is binding, and
if a rule seems wrong, say so deliberately and change it on purpose —
do not drift from it quietly.

* The plugin
=agent/opencode-plugin/node_modules= is NOT tracked in git and is excluded
from every gate scan. It is a SYMLINK to
=/root/home/shape/.config/opencode/node_modules=, the shared OpenCode
install, and that is deliberate: one copy of the dependencies serves
every plugin on this machine rather than one per checkout.

It was tracked as a symlink before this directory moved. It is now
untracked (the path is already in =.gitignore=), so a fresh checkout
does NOT get it, and the plugin will not run until the link is made:

#+BEGIN_EXAMPLE
cd AIU-PM/agent/opencode-plugin
ln -s /root/home/shape/.config/opencode/node_modules node_modules
#+END_EXAMPLE

=package.json= declares the dependencies; =npm install= is what would
produce a real directory here instead of a link, if a machine ever
needs one.

* What the plugin must not do
It must not reach past the JSON surface. Read is free; mutate needs a
human and the engine re-checks the confirmation itself. If the plugin
seems to need a new capability, the capability belongs in the engine
first, not here.

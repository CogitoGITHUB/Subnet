# One job: the package directory, the area law, and every planned directory and file with its single job
# Status: planned 2026-10-20; this file is the register for the package — a name that is not here does not exist yet.

* The package directory
# one subdir holds the whole package; nothing is scattered.
  - The package is =browser/=, directly under this project directory.
    The project root keeps context and docs (plan/, rules/, study/,
    research/, decisions/) plus gate/ and tools/.
  - =browser/INDEX.org= is created with the directory, one job per line;
    every subdirectory carries its own INDEX.org.
  - Nothing of the package lives outside =browser/=.

* The law
# areas lowest first; dependencies point one way; the language seam is named.
  - Areas, lowest first; a require may point downward only. The
    one-way lint transcribes this table as its source:
    errors, narration, machine, security, join, devloop, journal,
    commands, routes, input, drawing, files, picker, entry.
  - errors is the floor; entry is the ceiling.
  - Rule 09, named exactly (the editor's D-007): Rust owns the hot path
    — =input/=, =drawing/=, =journal/= and the listing; Racket owns the
    meaning side — commands, routes, files, rules and config. The seam
    is =join/=, and the meaning side is baked at build time and loads
    nothing at startup (D-008). =gate/language-split-lint.nu= keeps
    every other area clean.
  - One file, one job; the reader test on every name; banned words as
    in the ecosystem law.
  - The table is the plan; the first lint run lists any crossing it
    inherits, and each one gets a recorded decision, never silence.

* What starts first
# the first files, tied to the build order.
  - Lands first, with the light gate: errors, narration, machine and
    the =browser/= INDEX.org — the floor every later file stands on.
  - The first slice: join (the wire), files (the rows), drawing (the
    panel) — one real directory, listed and drawn.
  - The picker lands after the tree: the finder needs rows to find in.

* Absent on purpose
# what similar programs carry and this one will not.
  - No daemon; no plugin runtime; no terminal emulator; no file watcher;
    no icon set; no mouse-only feature; no language server; no
    core/, utils/ or description-name directories, ever.

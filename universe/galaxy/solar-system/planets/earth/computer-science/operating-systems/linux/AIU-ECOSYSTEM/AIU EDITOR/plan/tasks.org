* What a task is
# the shape, once.
  A task is a Racket procedure on the meaning side (rule 09): one
  name, one function, the reader test on the name. Its doc line is
  its help line. A task may call other tasks. The task table lives in
  =commands/tasks.rkt=, registered in plan/package-tree.org.

* What the study proved, and what is taken
# the harvest, one line per feature; what is refused, one line.
  - A task is a plain function: any procedure can be one.
  - Visibility is all or exports: no =#:export= means every function
    is a task; with an export list, only exports are.
  - =--list= and help come from the doc line, never a second list.
  - Runs take string arguments, exactly as typed after the task name.
  - Several runs in one invocation, in order (a sequence).
  - Dry-run, quiet and verbose as lexical scopes (parameterize) —
    with the wait door (rule 04) and work mode as the real safety.
  - Shell completions shipped as artifacts, landing with =entry/cli=.
  - The REPL workflow is =devloop/= work mode (rule 02) extended to
    tasks: redefine live, run again.
  Refused: the Emacs bridge; a runner in anything but Racket.

* What lands first
# the smallest slice, per rule 11; the done-when lives in TODO.org.
  The task table, one task, =--list=, and one run with arguments
  through print-console.rkt — the one printer. Then sequences; then
  the dry-run scope.

* What landed
# what is built now, and where the proof is.
  All of it, in =commands/tasks.rkt= and the two verbs in
  =entry/dispatch.rkt=, with the proof in TODO.org item 17 and the
  commit =fc8e437c=:
  - the task table holds one name and one function per task;
  - =cli.rkt tasks= lists every task with its doc line, and the doc
    line is the comment block above its own definition;
  - =cli.rkt task FILE NAME WORDS...= runs one task and prints its
    line through the one printer;
  - a =--= between two runs makes a sequence, and the runs go in the
    order they were given;
  - =--dry-run= opens the scope where a task that acts prints what it
    would do and changes nothing;
  - a name the table does not hold is refused by name.

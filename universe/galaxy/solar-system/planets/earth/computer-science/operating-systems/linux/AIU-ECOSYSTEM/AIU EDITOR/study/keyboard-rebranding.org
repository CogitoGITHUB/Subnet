* New names
# the AIU name that replaces it, with the reason.
  - neomacs becomes AIU Editor — the program's name; no new identifier carries
    "emacs".
  - Cyberdeck names stay with the old machine; the new program's binary takes
    its own name (open).
  - biomechanical-input-interface becomes keyboard — one plain word for the
    layer; the long phrase goes.
  - my/ becomes one prefix for config identifiers; which one is a naming
    decision, not this note's.
  - M-K is dropped; say state keymaps or the keyboard modes.
  - ks- / key-selection becomes selection — name the job; fix the prefix with
    the naming rules.
  - hydra / defhydra becomes menus; keep the declaration shape, lose the word.
  - Transient has no successor; the new program has its own menu surface.
  - state / substate becomes mode (this study's working term); keep "state"
    only if the plan keeps it.
  - lighter becomes the short state marker ([NOR] style), kept as data; the
    term itself is open.
  - leader stays (standard term); submenus become menu files.
  - chord stays — plain English.
  - act stays; dwim and the cycle/all/zap variants get plain names when wired.
  - upstream names survive only in license and attribution lines, never as
    identifiers.
  - stage tags become named load groups (boot, on-demand) when the format
    lands.
  - mechanism metadata keeps one tag per unit; the new tag name is fixed with
    the format.
  - directories get named for their job when the layout is replanned (cores/
    is the weak one).
  - AIU names stay as they are.
  - package names survive only as notes inside menu entries; menus speak their
    own titles.

* Where each appears
# which file or surface carries each old name, so nothing is missed.
  - biomechanical-input-interface and my/ — every file under engine/, cores/,
    leaders/ and states/, plus the validator messages.
  - M-K — comments in zz-universal and the state files.
  - ks- — cores/key-selection, leaders/keyselect, the states that bind it
    (dired, ibuffer, presentation, zz-universal).
  - hydra and Transient — leader files and engine/menus; defhydra also in
    engine/macros.
  - Stage tags and mechanism metadata — every heading in the layer.
  - Upstream names — the header lines of cores/*; each license line names
    where it was read.
  - Cyberdeck names — loader/, AIU-Frame, the cyberdeck file, dev menus.
  - neomacs — README and handoff prose only; not inside the layer.
  - AIU names — states/aiu-subnet, states/org-aiu-subnet, leaders/aiu-subnet,
    leaders/aiu-proxy; no change.
  - Package names — menu entries across leaders and states.

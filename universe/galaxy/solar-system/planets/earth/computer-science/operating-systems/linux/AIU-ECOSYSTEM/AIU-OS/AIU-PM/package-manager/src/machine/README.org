#+TITLE: machine — the machine's shape

* What this area does
=directories.rkt= is the ONE place that reads HOME or XDG (the other is
=env.nu= on the Nushell side). =cancel.rkt= is the cancellation door.
Cross-process exclusion is =racket/file='s =call-with-file-lock/timeout=,
called where the lock is taken (=git/vault-lock.rkt=, =queue/jobs.rkt=).
The lockFILE reader once named =file-lock.rkt= here now lives in
=store/lockfile.rkt=, beside the manifest it is read with.

* What it may depend on
=errors=, =narration=.

* What must never depend on it
=errors= and =narration= must never require =machine=. Every path read
outside this area is a second seam onto the filesystem, which is the thing
this area exists to prevent.

#+TITLE: Rule 01 — Never lose work
# One job: the hard rule and what it demands in this program
# Status: current; the rule text is the owner's and changes only with the owner.

* The rule
# the owner's words, repeated unchanged. Do not soften or reinterpret them here.
  Never lose work, stated honestly. Terminals are a facade over tty; a built-in session holder
  owns the shells and the screen is a thin client, detach and reattach. The editor journals
  every edit to disk as it happens, replayable after a crash. The plan says exactly what is
  protected on the phone (Termux + proot, where Android may kill background processes) and
  what needs a laptop, recorded in WHEN-ON-LAPTOP.org.

* What it demands here
# how this rule bites in this program. No examples; the plan carries the detail.
  The text on disk is the only source of truth; a crash never costs more than the last
  keystroke.

* What breaks it
# the failure this rule exists to prevent.
  A crash, a killed background process or an agent write that costs work with no way back.

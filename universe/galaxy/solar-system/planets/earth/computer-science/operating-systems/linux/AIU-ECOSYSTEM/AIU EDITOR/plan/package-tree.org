#+TITLE: Package tree — AIU EDITOR
# One job: the package directory, the area law, and every planned directory and file with its single job
# Status: planned 2026-10-17; this file is the register for the package — a name that is not here does not exist yet.

* The package directory
# one subdir holds the whole package; nothing is scattered.
  - The package is =editor/=, directly under this project directory.
    The project root keeps context and docs (plan/, rules/, study/,
    ui/, ai/, dev-mode/, ...) plus gate/, tools/ and agent/ — the
    same split as PM's =AIU-PM/package-manager/=.
  - =editor/INDEX.org= is created with the directory, one job per line;
    every subdirectory carries its own INDEX.org.
  - Nothing of the package lives outside =editor/=.

* The law
# areas lowest first; dependencies point one way; the language seam is named.
  - Areas, lowest first; a require may point downward only. The
    one-way lint transcribes this table as its source:
    errors, narration, machine, security, join, devloop, journal,
    buffer, notation, commands, checkpoint, routes, input, drawing,
    models, dashboard, send, picker, audit, entry.
  - errors is the floor; entry is the ceiling.
  - Rule 09, named exactly (D-007): Rust owns the hot path — =input/=,
    =drawing/=, =journal/= and the buffer's text state (input,
    drawing, layout, parsing, terminal handling). Racket owns the
    meaning side — commands, routes, models, rules and config. The
    seam is =join/=, and the meaning side is baked at build time and
    loads nothing at startup (D-008). =gate/language-split-lint.nu=
    keeps every other area clean.
  - One file, one job; the reader test on every name; banned words as
    in the ecosystem law.
  - The table is the plan; the first lint run lists any crossing it
    inherits, and each one gets a recorded decision, never silence.

* What starts first
# the first files, tied to the build order.
  - Lands first, with the light gate: errors, narration, machine and
    the =editor/= INDEX.org — the floor every later file stands on.
  - The first slice (checklist/tier-1 items 01 and 05): join (the
    Racket-in-binary probe decides D-008), buffer, journal, input,
    routes, commands, drawing — plain text opens, edits, saves.
  - The Racket join is proven on the laptop (item 01); if it fails,
    the external-process fallback is already named (D-008).

* Absent on purpose
# what similar programs carry and this one will not.
  - No daemon; no plugin runtime; no terminal emulator (the
    multiplexer holds terminals); no agent loop or RAG inside the
    editor; no desktop or web frontends.
  - No core/, utils/ or description-name directories, ever.

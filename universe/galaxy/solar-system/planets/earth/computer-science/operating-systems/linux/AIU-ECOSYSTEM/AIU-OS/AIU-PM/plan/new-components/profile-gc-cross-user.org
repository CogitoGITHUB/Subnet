#+TITLE: profile-gc cross-user reachability — see other users first
#+AUTHOR: Shape
# One job: make =profile-gc= compute reachability from every user's
# profile links before it deletes a generation. Status: planned only;
# nothing here is built, and no name here may be used by code until the
# register lists it (step 3). Source: =plan/MOVE-ORDER.org= step 28 and
# =plan/FEATURE-users.org=, whose per-user profiles this needs.

* Purpose
- Today everything is one owner's, so the collector can treat every
  generation it sees as its own. With per-user declarations (step 28)
  another user's profile can hold a generation the collector would
  delete; nothing else would notice, and the loss is permanent.
* Name and location
- name: =profile-gc= (the collector; changed in place; any rename is
  the register's business, not this file's)
- code: =src/install/profile-gc.rkt=
- area and layer: =install= (area 11 of 13)
- may require: everything below =install=
- may be required by: =entry= only
* Public interface, in plain words
- reclaim runs as before, but before deleting a generation it asks
  which users' profiles can reach it, and keeps it if any can.
* What it must never do
- Never guess from ownership: reachability is computed from profile
  links, for every user.
- Never delete a generation another user's profile holds.
* Tests
- =tests/install/= for the collector; the cross-user case gets its own
  test once =users-and-declarations= lands.
* Docs it updates
- =plan/FEATURE-users.org= (this is its reclaim half),
  =plan/PROGRESS.org=.
* Depends on new components
- =users-and-declarations=: per-user profiles must exist first.
* Build order
- With or just after step 28; before anything trusts =profile-gc= with
  more than one user on the machine.

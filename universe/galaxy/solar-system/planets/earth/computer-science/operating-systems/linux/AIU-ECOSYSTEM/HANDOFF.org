* What this ecosystem is
# Four separate programs that share one written contract and nothing else.
  - PM, the package manager, exists already and is in progress on the owner's side.
  - AIU TERMINAL MULTIPLEXER, AIU EDITOR and AIU NOTATION are planned here; their packages are planned, not built.
# Each works alone; none knows another's internals; if one crashes the others survive.

* Start here, in this order
# one line per step, so a fresh conversation knows where to begin.
  1. Read WORKFLOW.org, DECISIONS.org and SESSION-MAP.org in this directory.
  2. Read AGENTS.md, then HARD-RULES.org.
  3. Read the INDEX.org of this level for the map, then the project's own HANDOFF.org.
  4. Read the project's rules/ before designing anything binding.
  5. Read contract/ before designing anything that crosses programs.
  6. Read WHEN-ON-LAPTOP.org before promising phone behaviour.
  7. Read the project's TODO.org and plan/package-tree.org before building.

* Where everything lives
# one line per place, each with its single job.
  - WORKFLOW.org — the one workflow every session follows.
  - DECISIONS.org — the ecosystem decision log, append-only, newest first.
  - SESSION-MAP.org — which session works what, and in which order.
  - CLEANUP-LOG.org — retired or deleted docs, with the last live commit.
  - STATE.org — the ready-up survey; kept for the record.
  - research/ — one file per studied subject; lessons only.
  - contract/ — the one written contract between the programs.
  - learned/ — what the package manager already proved; PM is the read-only source.
  - agents/ — build instructions, plus the agent integration design.
  - pm-integration/ — what PM must gain; listed here, never done here.
  - checklist/ — the shared build up to the done line.
  - WHEN-ON-LAPTOP.org — the living list of phone limits.
  - ../text-editors/neomacs/ — the owner's literate config, read-only, for the editor study.
  - AIU-OS/AIU-PM — the package manager itself; read-only here.

* The rule sources, in the order they win
# when two sources disagree, the earlier one wins.
  - HARD-RULES.org — ecosystem-wide and checkable.
  - Each program's rules/ — the owner's hard rules, one file each.
  - Each program's decisions/ — program-only decisions; ecosystem ones land in DECISIONS.org.

* Purpose
- =error-message.rkt= maps an error kind to an exit code; two of those
  codes are invented locally and cite a proposal nobody approved. Exit
  codes are a public contract: scripts and agents read them.
- The owner's pick sets the numbers; this component is the mapping and
  wording change that lands afterwards.
* Name and location
- name: none new; the wording inside =error-kind->exit-code= changes,
  and with it the pinned tests
- code: =src/errors/error-message.rkt=
- area and layer: =errors= (area 1 of 13)
- may require: nothing
- may be required by: everything: the floor reports through it
* Public interface, in plain words
- unchanged: callers still map a kind to a code; the codes become a
  decision with a number, a name, and a citation that exists.
* What it must never do
- Never invent a code outside the decision: a new kind that needs a
  code amends the decision first.
* Tests
- =tests/errors/= pins the mapping; the pinned numbers change in the
  decision's commit, nowhere else.
* Docs it updates
- =plan/DECISIONS.org= (D-008 closes),
  =plan/OPEN-DECISIONS.org= (the question is answered).
* Depends on new components
- none.
* Build order
- After the owner answers; small; runs before any new component reads
  the exit contract.

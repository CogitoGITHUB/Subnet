* After reorganisation, in this order
Each feature gets its own =plan/FEATURE-*.org= design, its own commit, and
its README row flips from Planned to Current in the same commit. Every one
of them is designed in the FEATURE files and lands later; nothing here is
built yet. Design only until its step comes. The order of the list below is
the order they LAND in; README.md states the same order for the reader.

    =spec= or =apply=.

#+TITLE: Structured records
# One job: the one record shape for machine-readable output, shared by every program
# Status: filled 2026-10-16; working draft until a program and an adapter both depend on it.

* What this freezes
# the exact thing every program and adapter must obey; if it is not frozen here, authors guess.
  The one envelope every command emits: name, format, operands, then its
  result keys, in fixed key order, one object per line. Key order is a
  contract; readers diff on it. One shape for every reader — CLI, MCP
  server, skill, plugin, picker alike.

* Shape
# names and meanings only: the fields and what they promise. No code, no examples.
  - Envelope: name, format, operands, then result keys — fixed order,
    every operand a string.
  - Errors are exit codes, never error objects; a machine must tell
    "empty result" from "refused" and only the exit code can.
  - A refusal exits 0 and names its rule, what was rejected and what
    would be accepted; asking "what would this do?" is a normal read.
  - The command table is data — name, arity, mutating or not — and a
    check fails when the discovery table and the enforcement set
    disagree.
  - Documented examples execute in the test suite; a stale example fails
    the build.
  - New consumers never require new output paths; they read the one
    shape.

* Who obeys it
# every program and adapter this applies to, named.
  Every program's engine; every surface reads it and none re-implements
  it. Adapters obey it where they emit anything a program reads.

* How it changes
# how this can change without breaking a running client; point at a D-number once one exists.
  The envelope never grows silently; a command's result keys are part of
  its format and change with the contract version. Freeze condition: a
  program and an adapter both depend on it; none yet.

* Open decisions
# options with a recommendation, or none yet.
  - The format field's spelling — recommendation: name plus a version
    digit, so a reader can refuse a shape it does not know.

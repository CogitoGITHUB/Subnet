* How the gate is run
# the one entry point, and the two rules it keeps.
  - =nu gate/check.nu= runs every stage in order; =nu gate/check.nu --list=
    prints the stage table without running anything.
  - A stage with nothing to check prints NOTHING-TO-CHECK and never PASS; the
    dispatcher then prints how many stages checked nothing.
  - A lint starts checking for real by itself as soon as the area it watches
    exists. No stage needs an edit to the dispatcher to become real.

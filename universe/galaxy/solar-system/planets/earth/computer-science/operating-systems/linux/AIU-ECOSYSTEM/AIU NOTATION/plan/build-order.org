     back with nothing lost; plain writing needs almost no syntax —
     proof: parse, render and re-parse agree on a real page.
  3. Robustness: incremental reparse and error recovery on partial text

     recovers.

     states, links — proof: each element dispatches by name; the editor
     completes the names while typing.

     rebuilds, an unchanged one SKIPs naming the matched hash (mirrors
     the journal).

     commented text renders clean and the text keeps every comment.
  7. The engine surface: the boundary answers the editor; node
     addressing is stable; the loader works with the notation absent —
     proof: the editor's notation mode over the contract boundary
     (rule 14).
  8. Rendering tiers: plain and rich unicode on the phone's terminal;
     the graphics tier stays planned — proof: shown on the phone; the
     graphics question stays recorded as unproven.
  9. The kit: MCP server, skill with executed examples, read-only plugin
     — proof: the kit checklist runs green
     (agents/agent-integration-kit.org).
  10. Notation core hosted in the editor, the done-line share — proof:
      the done-line sentence holds and the shared checklist closes.

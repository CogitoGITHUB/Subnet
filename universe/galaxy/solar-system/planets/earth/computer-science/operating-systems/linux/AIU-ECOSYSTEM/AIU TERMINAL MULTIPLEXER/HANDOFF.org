* The phone traps this session found
# the ones that cost time, so nobody pays for them twice.
  - A pipe that is at its end says POLLHUP, not POLLIN. Checking only POLLIN makes the client spin forever on an empty stdin; check =POLLIN | POLLHUP= in both clients.
  - In Nushell, =print "x" | ^cmd= does NOT feed the external command: the string leaks to the terminal and the command gets an empty stdin. Use =^printf "x" | ^cmd=.
  - Nu 0.116 has no =let mut=; write =mut x = 0= when a variable is changed inside a loop.
  - Nu 0.116's =to json= prints several lines, so a JSON string built in a Nu script is broken; build the list by hand (=$words | each {|w| $"\"($w)\"" } | str join ","=).
  - In a Nu string only =$(...)= interpolates. A bare =$name= stays literal and makes the JSON wrong.
  - A screen that must stay attached needs a pipe that is never closed: a fifo that nothing writes to holds it open (the screen then waits on the holder, not on the keys).
  - =pkill -f "pattern"= kills the shell that runs it when the pattern is in the shell's own command line. Use =pkill -x holder=.
  - One client's socket breaking used to kill the whole holder; now the client is let go and the session goes on. The holder is the thing that must outlive every client.

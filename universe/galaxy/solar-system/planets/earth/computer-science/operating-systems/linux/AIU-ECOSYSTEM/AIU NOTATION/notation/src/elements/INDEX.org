* Files
# one line per file: its name, then the single job it performs.

  - register.rkt — the one table: name to meaning, and =require-known= which
    refuses a name this table does not carry
  - dispatch.rkt — a name and its body reach the right meaning, and =opaque?=
    says whether a block's body is opaque
  - literals.rkt — literal names: what a name is (bare lowercase word), what a
    block line is, and which of the two it is. It also carries =name-of=,
    =start-line?= and =end-line?=, which read the owner's three-line block
    form; those three were being edited on 2026-10-19 when this index was
    written, so read them as in flight, uncommitted.

* Where it sits
# why this area exists and what it may use.
  - Racket owns the meaning side (rules/rule-09-language-split.org). This area
    is the vocabulary: it says what a name means, and it is the only place
    that may add a name.
  - A name that is not in register.rkt has no meaning and must not reach the
    model; dispatch.rkt refuses it rather than guessing.

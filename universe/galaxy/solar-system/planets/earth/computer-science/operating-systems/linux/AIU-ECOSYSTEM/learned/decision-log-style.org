* How to read this file
# Verdict key: REUSE carries, ADAPT re-shapes, DO NOT REPEAT did not survive.

** Append-only, newest first, every entry citable
# The log is the archaeology the project refuses to do twice.
- What PM does: =plan/DECISIONS.org= is append-only, newest first; every entry is D-numbered and names the rule IDs and the files it touches ("Touches =file=; =file="); an amendment or reversal stays visible (D-027 reversed is kept, not erased).
- The rule: a decision that is not recorded cannot be trusted; a rule nobody can cite cannot be enforced.
- Verdict: REUSE — the ecosystem decision log follows this shape exactly.
- Read at: plan/DECISIONS.org (header and entries D-061..D-066).

** The entry shape: WHAT then WHY, one small block
# Every closing entry answers the same two questions in the same order.
- What PM does: entries carry a title line ("D-066: OPEN-DECISIONS retires; TODO.org is the order of record"), then =1. WHAT:= (what changed, precisely), then =2. WHY:= (why it had to). Batch entries close a whole file at once (D-044..D-066 closed OPEN-DECISIONS).
- The rule: the log holds policy and reasons; owed work belongs in TODO.org; done history in PROGRESS.org and git log.
- Verdict: REUSE.
- Read at: plan/DECISIONS.org D-063..D-066 (batch closings).

** Retiring an open-decisions file: reduce to a redirect, never delete
# Code, gates and designs cite paths; a path that dies takes their meaning with it.
- What PM does: =plan/OPEN-DECISIONS.org= became a redirect stub: where each question went (DECISIONS.org range; TODO.org for what is owed), the recovery command =git show 0fd8617:plan/OPEN-DECISIONS.org=, and one line of why it is kept rather than deleted.
- The rule: a cited path is an interface; retire it by redirect, and log the change in CLEANUP-LOG.org.
- Verdict: REUSE — the ecosystem's three plan/open-decisions.org files retire the same way.
- Read at: plan/OPEN-DECISIONS.org (the stub); plan/CLEANUP-LOG.org ("Reduced, not deleted").

** Defaults are marked, options carry recommendations
# A default taken without a recording reads as an accident.
- What PM does: options are listed with a recommendation; when a default is taken it is named in the decision (e.g. the eight carried answers in D-063, the parked-work deferrals in D-056).
- The rule: the default marked when used; the recommendation is the answer unless the owner overrides.
- Verdict: REUSE.
- Read at: plan/DECISIONS.org D-056, D-061, D-063.

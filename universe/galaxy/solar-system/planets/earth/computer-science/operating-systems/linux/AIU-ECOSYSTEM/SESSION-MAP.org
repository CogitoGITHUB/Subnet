* Read order for a fresh session
# so a new conversation starts correctly.
  1. This file, then WORKFLOW.org and DECISIONS.org at the root.
  2. The project's HANDOFF.org, then AGENT.md.
  3. The project's TODO.org (the only task list) and plan/package-tree.org (the register of every package name).

  - Then floors and slices: multiplexer 03–04 (holder, panes) beside editor 05 (plain text slice).

* Where the shared things live
# one line per shared artifact.
  - contract/ — the working draft; a piece freezes when a program and an adapter both depend on it; changes only through DECISIONS.org.
  - checklist/tier-1/ — the shared order of record; tier-2/ and tier-3/ after the done line.
  - WHEN-ON-LAPTOP.org — every phone limit, the moment it appears.
  - learned/ — what PM proved; the ready-up's topic files name their PM path.

* The rule about sessions
# one at a time.
  - One session per project; the others are read-only; no sub-agents.
  - A session works its TODO.org top to bottom; a blocked item never stops the run.

#+TITLE: Context bundle format
# One job: the one bundle a send carries: selection, file, position, notation address, and why
# Status: filled 2026-10-16; working draft until a program and an adapter both depend on it.

* What this freezes
# the exact thing every program and adapter must obey; if it is not frozen here, authors guess.
  What travels in a send: the bundle. One shape, so any program can
  send anything visible — buffer text, a notation node, a picker entry,
  a pane selection, a command record, a package, a plan, a failure — to
  any agent with its full context (rule 07).

* Shape
# names and meanings only: the fields and what they promise. No code, no examples.
  - Selection — the text, or none; file — the path, or none; position —
    where in the file; notation address — the node's address when the
    text is notation (this file's neighbour); why — what the sender was
    doing, mandatory.
  - Origin: which program sends, in which project; target: the named
    choice of agent, from the choosing rule — never inferred.
  - A document: a header, then references — paths, addresses, selections.
    An absent part stays absent; empty is not a value.
  - No agent-specific keys, ever: the adapter translates; the program
    never learns which agent answers.
  - No secrets: the bundle passes the redaction seam; an agent receives
    pointers and text, never credentials.

* Who obeys it
# every program and adapter this applies to, named.
  Every program sends bundles — the editor and the multiplexer most of
  all — and PM's senders use the same shape (package, plan, failure).
  Every adapter consumes it.

* How it changes
# how this can change without breaking a running client; point at a D-number once one exists.
  New fields are additive; senders fill what they have. Freeze
  condition: a program and an adapter both depend on it; none yet.

* Open decisions
# options with a recommendation, or none yet.
  - How large a selection may ride inline — recommendation: text inline
    up to a small budget; larger goes by reference plus its content hash.

(Emacs first, system later). The contract is =0.FOUNDATION.org= in this
directory; rule IDs (P-1, E-5, ...) are cited in commit messages.

* Status
Scaffold only (build-order step 1). No core code yet. Environment:
Racket 9.3 CS minimal in =~/opt/racket=, =rackunit-lib= installed.

* Layout
- =docs/= -- decisions, errors, glossary, lessons, perf baselines
- =scripts/check.sh= -- green gate (P-1, T-7)
- =core/=, =backends/=, =targets/=, =cli/=, =tests/= -- not yet created
- =reference/= -- frozen Guix originals, read-only (not yet populated)

* Verify

before every commit.

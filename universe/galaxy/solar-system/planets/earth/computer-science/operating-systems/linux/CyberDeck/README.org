#+TITLE: CyberDeck package manager
#+AUTHOR: Shape

* Purpose
Target-neutral declarative package manager in Racket. The contract is
=0.FOUNDATION.org= in this directory; rule IDs (P-1, E-5, ...) are
cited in commit messages.

* Status
Core, backends, CLI check, Emacs-free. Environment: Racket 9.3 CS
minimal in =~/opt/racket=. Run =scripts/check.nu= before every commit.

* Layout
- =docs/= -- decisions, errors, glossary, lessons, perf baselines
- =scripts/check.nu= -- green gate (P-1, T-7), Nushell
- =core/=, =backends/=, =cli/= -- specs, plans, git, execution
- =tui/= -- terminal package explorer (Rust, snapshot-file seam)

* Verify
Run =opt/nushell/0.116.1/nu scripts/check.nu= from this directory. Nu
is pinned to 0.116.1 (D-020) and the gate refuses any other version.
One shared-process runner tests EVERY =.rkt= in the tree: a slow file
is an error to investigate, never a reason to give it its own process
or its own tier. Between checklist items run =nu scripts/check.nu
--changed= (changed files plus the test blocks of the modules that
require them); the full gate runs once per phase. The verdict is
ALL GREEN, ALL GREEN (jobs parked) or CHECK FAILED, and CHECK FAILED
exits non-zero. The runner prints =TEST-START=/=TEST-END= per file with
=at= (elapsed since the run started), a =SUSPECT:= line for anything
over 2000 ms, and a =SLOWEST= block. All of that is information: nothing
waits on a clock.

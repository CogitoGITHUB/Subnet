#+TITLE: CyberDeck package manager
#+AUTHOR: Shape

* Purpose
Target-neutral declarative package manager in Racket. The contract is
=0.FOUNDATION.org= in this directory; rule IDs (P-1, E-5, ...) are
cited in commit messages.

* Status
Core, backends, CLI check, Emacs-free. Environment: Racket 9.3 CS
minimal in =~/opt/racket=. Run =scripts/check.nu= before every commit.

* Layout
- =docs/= -- decisions, errors, glossary, lessons, perf baselines
- =scripts/check.nu= -- green gate (P-1, T-7), Nushell
- =core/=, =backends/=, =cli/= -- specs, plans, git, execution
- =tui/= -- terminal package explorer (Rust, snapshot-file seam)

* Verify
Run =opt/nushell/0.116.1/nu scripts/check.nu= from this directory. Nu
is pinned to 0.116.1 (D-020) and the gate refuses any other version.
It must print ALL GREEN before every commit, or FAST GREEN (partial)
with =--fast=.

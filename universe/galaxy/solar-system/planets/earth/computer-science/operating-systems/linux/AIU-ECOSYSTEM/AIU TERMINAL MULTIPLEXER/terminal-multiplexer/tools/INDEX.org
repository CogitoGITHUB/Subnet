* Files
# one line per file: its name, then the single job it performs. This index is updated in the same commit as any change here.

  - tiny-binary-probe/probe.rs — the tiny binary the route decision rests
    on: it starts, and says so
  - tiny-binary-probe/measure.nu — builds the probe on this phone and
    prints the measured build and start times
  - holder-probe/probe.nu — the phone proof of the holder: a client attaches,
    detaches, and the shell is still alive and still writing to the log
  - mcp-probe/probe.nu — the phone proof of the agent surface: an AI agent
    lists the sessions, sends to a session, and is refused without the
    human's token
  - panes-probe/probe.nu — the phone proof of the panes: a layout opens its
    panes, every pane's shell is alive, and each pane's output is recorded
    under that pane's own name
  - devmode-probe/probe.nu — the phone proof of the dev mode: one running
    client takes a change to the config in force without a restart, and the
    bake keeps the last good
  - screen-probe/probe.nu — the phone proof of the screen: the panes are
    drawn on one terminal, the mode line says the mode, the keymap explorer
    opens on Space and shows the keys, and a key in insert mode reaches the
    focused pane's own program
  - send-probe/probe.nu — the phone proof of the send to both agents: the
    selection, the command record and the why travel in one bundle to the
    multiplexer's own agent and to the editor's agent, and the seam holds a
    secret out
  - routing-probe/probe.nu — the phone proof of the routing walk: a key
    reaches the program in the focused pane first, the reserved prefix stays
    the multiplexer's in every mode, and the walk needs no mouse
  - editor-probe/probe.nu — the phone proof of asking the editor: the
    multiplexer asks the editor's own server for what the editor owns, and
    the answer is the editor's own words
  - control-probe/probe.nu — the phone proof of the agent's hands: an agent
    drives the multiplexer the way the owner does — a tab, a split, a
    scroll, a copy and a paste — and a change without the human's token is
    refused by name

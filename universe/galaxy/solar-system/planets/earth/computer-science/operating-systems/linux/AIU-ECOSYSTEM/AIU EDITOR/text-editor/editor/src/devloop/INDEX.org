* The area
# what the area is and what it owes.
# The work mode loads the config live from the source: the tables are
# read at every start, so an edit to the source is seen at the next
# start. The bake makes the config into first-class defaults in a
# generated module, so the baked program carries them inside it and
# needs no user config at startup.
#
# There is NO timer and no watcher in here. The rebuild is manual: the
# owner starts it when they decide, it may run long, and it says what it
# did when it is done. The measured start is information, not a gate.
#
# The devloop area is BELOW the routes, so it may not require them: the
# bake takes the config as an argument and the entry decides what the
# config is.

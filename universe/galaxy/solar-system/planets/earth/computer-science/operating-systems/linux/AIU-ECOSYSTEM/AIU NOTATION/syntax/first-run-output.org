* What the output named, and what was fixed
# two failures, each fixed once, each because the output named it.
  - 1. =err.rkt= used =#:methods gen:custom-write= and failed with "write-exn:
    unbound identifier". This build has no =gen:custom-write= ("bad require
    spec"). Fix: the record carries no writer of its own; printing is
    =render.rkt='s one job.
  - 2. The document showed a nested =node block code ... depth 1= and an
    =unclosed-block= error, because the parser read inside an opaque code body
    and took the bare =code start= line as a nested open. That breaks rule D.
    Fix: =parser.rs= now skips every line inside a code block except an exact
    matching end line. After the fix the document above is correct.

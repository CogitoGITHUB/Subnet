#+TITLE: First run — what the notation engine does with a real page
# One job: the captured output of one real run, so a reader can see what the
# engine does without running it.
# Captured 2026-10-19 on the phone, from the commands below. Nothing here was
# written by hand; every line is output that was seen.

* The page
=syntax/example.aiu= — 564 bytes.

* The commands
The binary is built into =/tmp/notation-target= and the Racket side is run
with a RELATIVE path from the project directory, because the project
directory holds a space and racket splits a path argument on it.

#+BEGIN_EXAMPLE
cd "<project dir>"
B=/tmp/notation-target/debug/notation
R=/root/home/shape/opt/racket-full/bin/racket
#+END_EXAMPLE

* 1. The round trip
The page must print back to the very same bytes.
#+BEGIN_EXAMPLE
$B roundtrip syntax/example.aiu
roundtrip: identical (564 bytes)
exit=0
#+END_EXAMPLE

* 2. The parse
The page becomes a parse tree document. The shape is frozen in
=notation/src/join/INDEX.org=: a node line, its =decl= lines, its children,
and =end= at the end.
#+BEGIN_EXAMPLE
$B parse syntax/example.aiu
parse-ms: 0
NOTATION-DOCUMENT 1
file "syntax/example.aiu"
node block title 1 0 4 66 0
decl tags "sample first-run" 2 12
node block paragraph 6 68 10 300 0
node block paragraph 12 302 16 499 0
node block code 18 501 22 563 0
decl language "text" 19 512
end
#+END_EXAMPLE
The numbers are: the name, the line, the start byte, the end line, the end
byte, the depth. The code block is at depth 0 and holds no child: its body is
opaque.

* 3. The plain render
The marks, the declaration lines and the comments are gone; the content is
kept.
#+BEGIN_EXAMPLE
$B render syntax/example.aiu
The first sample page
Every line of this page sits inside a named block. A block is three lines of
shape: the name and start, the content on its own line or lines, then the name
and end again. The keyword always comes first.
The code block below holds a line that looks like a start line. The body of a
code block is opaque, so that line is content and opens nothing. Only code end
closes it.
def example():
    return 1
exit=0
#+END_EXAMPLE

* 4. A broken copy
One line of loose text was put after the title block. The engine does not
throw the page away: it keeps every block and names the broken line.
#+BEGIN_EXAMPLE
$B parse /tmp/aiu-audit/broken.aiu
parse-ms: 2
NOTATION-DOCUMENT 1
file "/tmp/aiu-audit/broken.aiu"
node block title 1 0 4 66 0
decl tags "sample first-run" 2 12
error stray-text 5 67 0 "text outside any named block" "put the text inside a ""<name> start"" / ""<name> end"" block"
node block paragraph 7 100 11 332 0
node block paragraph 13 334 17 531 0
node block code 19 533 23 595 0
decl language "text" 20 544
end
#+END_EXAMPLE
The error line carries the kind, the line, the byte, the line the block was
opened at, what is wrong and what to do.

* 5. The check, on a good page
The Racket =check= command reads a PARSE TREE DOCUMENT, not a .aiu page, so
the document from step 2 is what it is given.
#+BEGIN_EXAMPLE
$R notation/src/entry/cli.rkt check /tmp/aiu-audit/example.document
syntax/example.aiu: no errors in the parse tree document
exit=0
#+END_EXAMPLE

* 6. The check, on the broken page
#+BEGIN_EXAMPLE
$R notation/src/entry/cli.rkt check /tmp/aiu-audit/broken.document
ERR /tmp/aiu-audit/broken.aiu at line 5, column unknown: parser-recovery: the parser recovered from stray-text: text outside any named block; what to do: put the text inside a "<name> start" / "<name> end" block
/tmp/aiu-audit/broken.aiu: 1 finding(s); the document is not clean
exit=1
#+END_EXAMPLE
The column says =unknown= because a parse tree document carries no page.

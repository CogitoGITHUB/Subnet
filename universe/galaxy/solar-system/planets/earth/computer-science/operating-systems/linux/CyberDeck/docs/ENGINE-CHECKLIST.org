* Rules for a resuming session
Read =docs/ENGINE-CHECKLIST.org=, =docs/ENGINE.org= and
=docs/DECISIONS.org= first, in that order. Then do the first item still
marked TODO. Between items run =scripts/check.nu --changed=; run the
full gate at the end of each phase. One item is one small commit. The gate must be green before
the commit: run =--fast= between items and the full gate at the end of
each phase. Mark the item DONE with its commit hash in the SAME commit
that does the work, never in a later one. Never skip ahead: an item that
looks wrong is fixed or reported, not reordered. Stop only if the gate
goes red or the item is genuinely ambiguous. Synthetic fixtures only
(T-10). No timers anywhere (D-015). Nothing outside =CyberDeck/=. No
push.

** BLOCKER P-04 and P-03: jobs.rkt hangs before its own tests finish

test and never returns: the parent kills the lock holder, THEN opens
=k-die= for reading; the holder is already dead, so no writer ever
appears and =open-input-file= blocks forever. Deterministic, not a race.

call before that block.

=/tmp/pm-runs/nu-full.log= (01:31 full gate) ends with TEST-START
=backends/jobs.rkt= and has 0 TEST-END lines. Eight stale
=/var/tmp/pm-jobs*= dirs remain, the oldest from 2026-10-09 10:38.
The P-04 tracing change is written and balanced but NOT committed: the
gate cannot go green until the fifo test is fixed. Patch kept outside the
tree. Fix the fifo ordering first, then re-run P-04.

#+TITLE: Non-goals — AIU TERMINAL MULTIPLEXER
# One job: what this program will never do, and which tempting things are refused anyway
# Status: filled 2026-10-16; plans stay general, not yet reviewed.

* Deliberately not done
# one line per thing this program will never do, with the reason.
  - Config and timers in the holder — rule 03: it only holds terminals and
    the log; settings live in the client.
  - A process-survival promise Android cannot keep — restore is honest;
    processes die (WHEN-ON-LAPTOP; the tty and pty study).
  - A plugin runtime — extension surfaces are MCP and skills; the plugin
    ecosystems of the studied multiplexers stay out.
  - Mouse-required anything — rule 13; the mouse may work, it is never the
    path.
  - Becoming the editor — it hosts programs in panes; editing is the
    editor's job.
  - A desktop or web client, discovery protocols, chat gateways — network
    surface this phone does not need.

* Tempting but out
# things that look useful and are still refused, with the reason.
  - Growing a full-featured multiplexer before the first tiny binary is
    proven on this phone — the synthesis test comes first.
  - Copying a studied multiplexer's whole surface — take pane status,
    socket control and layouts as files; leave the marketplaces.
  - Promising rich graphics in panes — the terminal's graphics tier is
    unproven here and stays recorded as such.
  - Replacing the contract with adoption — whichever tool is used must sit
    behind the same written contract, or the migration path dies.

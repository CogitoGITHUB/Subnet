#+TITLE: Rule 10 — Free UI placement
# One job: the hard rule and what it demands in this program
# Status: current; the rule text is the owner's and changes only with the owner.

* The rule
# the owner's words, repeated unchanged. Do not soften or reinterpret them here.
  Free UI placement, a hard need. Every UI element (modeline, tab bar, buffer bar, sidebar,
  panel, status area) is a placeable piece with an edge (left, top, bottom, right, or
  floating), a size, an order and its content. Any piece can go on any side. Many at once:
  several modelines, several tab and buffer bars, stacked or on different edges. Each piece
  can show agent status: idle, working, waiting for my accept, which agent, on what. Placement
  is decided by Racket config and baked by dev mode. The Rust UI engine only draws what the
  config describes.

* What it demands here
# how this rule bites in this program. No examples; the plan carries the detail.
  Modeline, tab bar, buffer bar, sidebar and panels are placeable pieces; placement is Racket
  config, baked by dev mode.

* What breaks it
# the failure this rule exists to prevent.
  A layout the config cannot describe, or a piece welded to one edge.

* What this package is
# one paragraph: what it is for, and what it is not.
  The Git inspection layer: the one read-only model of a repository that the
  text editor and the terminal multiplexer both read. It owns the
  discovery, the commands, the parsing, the states and the freshness. It
  changes nothing: it never stages, commits, checks out, merges, stashes,
  fetches, pushes or touches a worktree, and no command it can run would
  do any of those. A change of state is a different program, with declared
  permissions.

  The design it follows is in =plan/git-inspection.org=.

* Files

  - INDEX.org — the file register of the Git inspection layer
  - Cargo.toml — the crate manifest: the library, the one-shot program, and
    the two crates the phone's registry holds
  - plan/ — the design of the layer, written before the code
  - plan/git-inspection.org — the assessment of the two trees, the read-only
    boundary, the model, the worktrees, and the order the stages land in
  - src/ — the code of the layer, one module per job

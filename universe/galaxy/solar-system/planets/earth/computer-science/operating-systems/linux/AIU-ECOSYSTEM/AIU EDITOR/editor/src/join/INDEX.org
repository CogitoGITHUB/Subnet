  - INDEX.org — this index: every file of the join area and its one job

  - racket-entry.rkt — the meaning side's entry: one request in, one response out
  - load.rkt — where the meaning side is reached; the one call that asks it

* The area
# The join area is the only place the two languages meet (rule 09).
#
# On this phone the meaning side cannot be baked into a binary, so it runs
# as an external Racket process and the wire between the two is one line of
# JSON per message. The numbers that forced this are in
# research/join-on-the-phone.org; the decision is D-008 in the root
# DECISIONS.org.
#
# The wire travels through two files, one for the request and one for the
# response, and that is a fact of this Racket build rather than a choice:
# racket/system hands a child process /dev/null for every stream that is
# not a file stream, so a child given a pipe is mute. The message shape is
# unchanged: one line of JSON each way.
#
# rust-exports.rs, the functions the meaning side may call, lands with the
# first Rust file: there is no Rust in this program yet.

# how a decision is written here.
  - One file per decision, newest first in this index.
  - Each file says: what was decided, why, what it costs, and what it
    takes to undo it.
  - A decision that crosses programs needs a D-number in the root
    DECISIONS.org, and the root log is read-only from this project.

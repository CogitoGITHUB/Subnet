#+TITLE: Outputs — AIU EDITOR
# One job: what exists at the end, what it is good for, and what is not shipped
# Status: filled 2026-10-16; plans stay general, not yet reviewed.

* What exists at the end
# one line per thing a user can hold or run when this plan is done.
  - The editor binary — baked, opening instantly with no config, printing
    its measured start — and its work-mode config loading live from
    source.
  - The journal and its replay: edits survive a kill.
  - Select and send to both agents from the editor, the full done-line
    half of the shared checklist.
  - Live audit with agent and external marks, accept and undo; the git
    checkpoint and the stop switch.
  - The notation hosted: engine loads through the boundary and bakes in;
    the loader is independent of it.
  - The dashboard display and the proven key routing across multiplexer,
    editor and panes.
  - The kit — the engine's JSON surface, its MCP server, the skill whose
    examples run, and the read-only plugin — plus the event feed.
  - The editor's own checklist after the split (tier-2 content), as the
    continuing plan.

* What it is good for
# the everyday uses, in plain words.
  Plain-text editing on a phone over a shell; vault work with keys alone;
  sending anything visible to an agent in one action and watching, keeping
  or undoing what it does; writing and reading notation once the engine
  lands; building the engine from inside the editor; keeping work safe
  across kills and agent writes.

* Not shipped
# things deliberately left out of this output set.
  Desktop or web clients; a plugin marketplace; an embedded agent loop or
  RAG; mouse-first flows; the old config as it is; the advanced notation
  tiers (math, graphs — far future, plan only).

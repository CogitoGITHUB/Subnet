** 2026-10-06 srcloc columns print raw Racket values (already 1-based)
Probes (read-syntax + port-count-lines!): datum at file offset 0
reports column 1; at offset 2 reports column 3. No +1 is added; this
matches editor/GCC convention. Pinned by the spec.rktd:1:1 and 1:3
tests in core/errors.rkt. P-8.

** 2026-10-06 Log macros bypass contract-out (M-3 exception)
Verified in the REPL: =define-logger= level forms (=log-pm-debug=,
=log-pm-info=, ...) are macros, so they cannot go through
=contract-out= (or even be referenced as values). =core/log.rkt=
provides them bare; everything else in the module is contracted. M-3.

** 2026-10-06 D-005 details: current symlink, Emacs stamp file
One =current= symlink per package (=racket-mode -> racket-mode-<v>/=);
the loader points at =current= so upgrades/rollbacks never touch it.
A stamp file records the Emacs version; recompile when it changes.
[VERIFY on the user's Emacs]. Manager state (lockfile, logs, cache)
lives in a separate state dir, never with installed packages. D-005.

** 2026-10-06 D-006 HARD: git only, always full clone
No other source or package manager, ever. Every install clones the
full repo so the source survives even if upstream vanishes. D-006.

** 2026-10-06 D-009 details: data-only, Tier B own-repo only
Tier B is only for files in our own repo, never fetched. A =(run ...)=
step gets a visible plan marker and warns in =--strict= mode (E-11).
Dry-run is the default for outside-repo specs. D-009, S-1.

** 2026-10-07 RULING: VAULT MONOREPO (supersedes both D-011 wordings)
One bare repo CyberDeck/sources/vault.git (outer-gitignored) holds all
package sources, one namespace per package: refs/vault/<name>/heads/*,
refs/vault/<name>/tags/*, refs/vault/<name>/pinned/<commit>. Tags stay
namespaced (v1.0 collides across packages). Never mirror refs/pull/*
or other hosting refs: measured on magit, heads+tags = 36M, +pull =
86M (+50M, 2784 junk refs), so provider refs are pure cost. Full
history always, no shallow. `pm add` is one atomic op under a vault
lock (validate, fetch namespace, verify pin, pin ref, append manifest,
print sizes; failure changes nothing; never pushes). Backup is ONE
user-owned remote: explicit `pm backup` pushes refs/vault/*,
`pm restore` rebuilds, `pm vault status` compares. Export unchanged
(--git-dir=vault.git, checkout at pin into empty staging). gc is
explicit-only (`pm vault gc`, phone-sized limits) plus `pm vault
verify` (fsck): one repo is a single corruption point. D-011, D-012.

** 2026-10-06 STEP C: export interface (design only) + D-014 decided
Export is checkout-based from the mirror at the pin into an empty
staging dir (no implementation yet). Interface for backends/git.rkt:
#+begin_example
(provide (contract-out
 [git-export-commit (->* (path-string? string? path-string?)
                         (#:timeout exact-positive-integer?)
                         void?)]))
;; mirror-dir commit-id staging-dir -> void
#+end_example
Exact commands: git --git-dir=<mirror> cat-file -t <commit> (must be
commit, else kind 'verify); git clone --quiet --no-checkout
-c core.autocrlf=false -c core.attributesFile=/dev/null -- <mirror>
<work-tmp>; git --git-dir=<work-tmp> with the same -c flags checkout
--quiet <commit>; refuse mode 160000 (submodules) kind 'fetch with a
future-work hint; delete work-tmp/.git; copy the tree (modes and
symlinks kept) into staging; stamp staging/.cyberdeck-commit with the
id; symlinks escaping the tree are kind 'fetch; work-tmp is removed
always, staging is left empty on failure. Staging must sit on the same
filesystem as the final target (caller ensures it). STEP C.
D-014 DECIDED: no runtime syntax/parse (+4.4s); spec validation is a
hand-written table-driven validator over read-syntax objects. D-014.

** 2026-10-06 Mirror safety: keep everything (item 8)
Mirrors set core.logAllRefUpdates=always, transfer.fsckObjects=true,
gc.pruneExpire=never, gc.reflogExpire=never,
gc.reflogExpireUnreachable=never. Rationale: the vault promise is to
never lose original code; disk is cheaper than resurrection.
Storage cost: unreachable objects accumulate forever; acceptable for
a personal package set, revisit if the vault outgrows the phone.
Key names cross-checked against long-standing git behavior; the real
proof is the pin-survival test (prune=now plus fetch.prune=true).

** 2026-10-06 Export experiment verdict: checkout-based (D-011)
Fixture repo (nested dir, exec bit, export-ignore file): =git archive=
silently omits export-ignored files, modes and other contents
identical. Checkout-based export (clone/checkout at pin, copy tree
minus .git) is fully faithful. =git archive= only if a package
explicitly opts into export-ignore semantics (future work). P-8.

** 2026-10-06 git env + exit codes probed live (git 2.53.0)
GIT_ALLOW_PROTOCOL=https:ssh:file: ext:: denied with and without it
(default-deny noted); file:// works under it. GIT_TERMINAL_PROMPT=0
plus ssh BatchMode fails fast offline with no prompt; full
prompt-suppression proof needs an auth challenge (deferred).
Exit codes: present commit = =cat-file -t= exit 0 printing "commit";
absent id = exit 1 silent; tree/blob = exit 0 with other type
(existence is NOT enough, must check the type); not-a-repo = exit
128 with fatal message. Mapping: commit->#t, absent/non-commit->#f,
anything else raises kind 'fetch with E-8 fields. P-8, E-8, E-14.

** 2026-10-06 D-006 git ONLY; D-011 vault; D-012 pin refs
Sources are git and nothing else: no tarballs, no MELPA, no other
archive or manager. Every package keeps a full mirror (=git clone
--mirror=) in =~/.local/share/cyberdeck/vault/<name>.git=. Installs
export from the mirror at the pinned commit, never from the network;
updates are =git fetch= into the mirror (D-011). Installing a commit
creates a private ref =refs/cyberdeck/pinned/<commit>= so force-pushes
and gc cannot make it unreachable (D-012). Pin = full commit id
(40 hex, 64 for sha256 repos), never a branch or tag alone. D-006.

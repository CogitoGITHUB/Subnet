** 2026-10-06 D-006 git ONLY; D-011 vault; D-012 pin refs
Sources are git and nothing else: no tarballs, no MELPA, no other
archive or manager. Every package keeps a full mirror (=git clone
--mirror=) in =~/.local/share/cyberdeck/vault/<name>.git=. Installs
export from the mirror at the pinned commit, never from the network;
updates are =git fetch= into the mirror (D-011). Installing a commit
creates a private ref =refs/cyberdeck/pinned/<commit>= so force-pushes
and gc cannot make it unreachable (D-012). Pin = full commit id
(40 hex, 64 for sha256 repos), never a branch or tag alone. D-006.

** 2026-10-06 Open questions (defaults proposed, user picks)
Export method: =git archive= can silently omit files (export-ignore);
test it against a checkout-based export and pick the faithful one
[VERIFY]. Default: checkout-based export unless archive proves
faithful. Submodules: error out by default (loud, P-7); mirroring
them too is future work. Shallow clones: default NO, full original
always; explicit per-package opt-in only. D-011.

** 2026-10-06 CORRECTION: srcloc columns are 0-based, ui prints +1

form (span 2 at offset 1), so column 1 meant 0-based, not 1-based.

** 2026-10-06 Log macros bypass contract-out (M-3 exception)
Verified in the REPL: =define-logger= level forms (=log-pm-debug=,
=log-pm-info=, ...) are macros, so they cannot go through
=contract-out= (or even be referenced as values). =core/log.rkt=
provides them bare; everything else in the module is contracted. M-3.

** 2026-10-06 D-005 details: current symlink, Emacs stamp file
One =current= symlink per package (=racket-mode -> racket-mode-<v>/=);
the loader points at =current= so upgrades/rollbacks never touch it.
A stamp file records the Emacs version; recompile when it changes.
[VERIFY on the user's Emacs]. Manager state (lockfile, logs, cache)
lives in a separate state dir, never with installed packages. D-005.

** 2026-10-06 D-006 HARD: git only, always full clone
No other source or package manager, ever. Every install clones the
full repo so the source survives even if upstream vanishes. D-006.

#+TITLE: INDEX — AIU TERMINAL MULTIPLEXER/multiplexer/
# One job: list every file and directory in the package and the single job of each.
# Status: current; updated in the same commit as any change in the package.
#
# This file is the register the gate reads: the naming-register stage fails when
# a path here names nothing, or a path in the package is named nowhere.

* Files
# one line per file and directory: its name, then the single job it performs.

  - INDEX.org — this index: every file and directory of the package, with its job
  - Cargo.toml — what the package is: the holder and the client, and the two
    crates this phone can fetch
  - Cargo.lock — the exact versions of those two crates, pinned
  - src/ — the package's source, one area per directory: Racket areas and Rust
    areas
  - src/errors/ — the error type and how it renders (the floor of the area table)
  - src/errors/INDEX.org — the error area: the record, the raise, the render
  - src/errors/err.rkt — the error record: what happened, who, where
  - src/errors/raise.rkt — the one raise helper; nothing raises around it
  - src/errors/render.rkt — how an error prints: one shape, never a dump
  - src/narration/ — how work speaks: events, the wait door, the printer
  - src/narration/INDEX.org — the narration area: events, voice, wait, printer
  - src/narration/events.rkt — the event record: schema only, decides nothing
  - src/narration/narration.rkt — a run's voice: open, step, note, warn, skip, decide
  - src/narration/wait-door.rkt — wait-for / wait-done; why is never blank
  - src/narration/print-console.rkt — the ONE printer to the terminal
  - src/machine/ — the machine seam and the block door
  - src/machine/INDEX.org — the machine area: environment, locks, the door
  - src/machine/directories.rkt — the one place HOME / XDG is read
  - src/machine/locks.rkt — one-writer locks: wait and retry, never force
  - src/machine/cancel.rkt — the cancellation door every blocking call passes
  - src/tty/ — the terminal and the one way to open one
  - src/tty/INDEX.org — the tty area: the terminal, the facade, the measurement
  - src/tty/tty.rs — the terminal: raw mode, window size, escape handling
  - src/tty/facade.rs — the one way shells and panes touch a terminal: open a
    pty, size it, read and write bytes
  - src/tty/measure.rs — what works under proot is measured, never assumed
  - src/holder/ — the session that outlives every client
  - src/holder/INDEX.org — the holder area: the session, the shells, the log
  - src/holder/holder.rs — the session: outlives every client, and serves the
    socket
  - src/holder/shells.rs — the shells of one session: started on a terminal and
    tracked
  - src/holder/log.rs — one append-only log file per session, flushed per record
  - src/holder/layout.rs — the layout file: the panes a session holds, by name
  - src/holder/wire.rs — the session's wire: one JSON object per line, both ways
  - src/agents/ — the door an AI agent comes in by
  - src/agents/INDEX.org — the agents area: the server, the tools, the envelope
  - src/agents/mcp.rs — the MCP server over stdio: one request per line, one
    answer per line, the one envelope
  - src/agents/tools.rs — the capabilities as data, and the work of each one
    over a session's wire
  - src/agents/envelope.rs — the one envelope every surface answers with
  - src/agents/capabilities.json — the declaration: the names, whether each one
    changes what a session does, and what it is for
  - src/client/ — the thin screen that attaches to a holder
  - src/client/INDEX.org — the client area: one program, one job
  - src/client/client.rs — the client: attaches, asks, reads and detaches; it
    holds nothing of its own

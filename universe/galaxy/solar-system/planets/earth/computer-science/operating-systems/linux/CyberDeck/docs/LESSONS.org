** 2026-10-07 Real data leaked into a test (T-10)
The resolve exact-message test used hl-todo v3.9.4 / compat 31.0 after
the design doc was fixed to real versions. Real pins belong in docs,
never in test constants: a future upstream change must not break the
suite, and fixtures must read as invented. Reverted to synthetic
names. New rule: tests use demo/unfill-style fixtures only. T-10.

** 2026-10-06 Assumed the measured syntax form's offset (P-10)
The srcloc probe measured the INNER culprit (=42=, span 2 at offset 1),
not the outer datum (offset 0). I concluded columns were 1-based and
committed a test pinning it. A span-printing probe proved 0-based.
Root cause: asserted about data I had not fully identified. New rule:
when a probe surprises, print the span/identity of the measured form
before concluding. P-8, P-10.

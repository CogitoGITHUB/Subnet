#+TITLE: PHASE 6: GUIX-PKGS-TUI remaster plan (design only, no code)
#+AUTHOR: Shape

* Inventory (amended D-018: terminal-only, no web, no graph)
DONE: rebranded to tui, web UI and graph/mind-map removed, indexer
reads the snapshot JSON file (--snapshot, $CYBERDECK_SNAPSHOT,
./snapshot.json), cache under ~/.cache/tui.
KEEP: src/search.rs (nucleo fuzzy worker), src/index.rs (in-memory
index plus BFS), src/cache.rs (gzipped cache), src/theme.rs (8
palettes plus NO_COLOR), src/app.rs (state plus keys), tests/ layout
with fixture data.

* IPC: DECIDED (amended D-018)
The TUI reads one snapshot JSON document (the CLI seam); the package
manager's s-expression output feeds snapshot producers later. No
long-lived stdio child. No TUI-only capabilities: anything the TUI
shows, the CLI prints.

* Screens map to operations
List shows inventory; detail shows package data (source, pin, status).
Check/review/apply/history screens wait on the STEP 5 s-expression
CLI. Offline mode marks stale data, like the CLI.

* Safety
The pm never shells out to the TUI and the TUI never writes vault
state. D-015 event loop for the TUI is queued for end of stage.

* Rule per step
No test runs between steps. =read-check= on the touched files, =raco make= on
the touched files and their direct dependents, then the commit. If =raco make=
is red, fix it before moving on: a compile error is not a test.

* The one tightening of that rule
A split is the only step where a wrong-but-compiling result is invisible until
the very end, when the tree has moved far and localising the fault is
expensive. So each split also runs =raco test= on the files it produced and
checks the total against the count from before the split. That is a compile
plus identity check, not a gate run, and it is why the split steps are the only
ones that do it.

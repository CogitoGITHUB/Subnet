* The three splits that were not done by subagent, and why
Steps 6, 7 and 8 were each handed to a subagent and each was cancelled.
The reason is the same and it is not the code: the account can only run
the free subagent model, and each split asked it to read a 650+ line file,
emit five to eight new files, redistribute every test, and run the suite
twice. Hours passed with a load average of 0.12 and no racket process
running -- the machine was idle and the model was not keeping up.

All three were then done directly, one session each, no subagent. The
facade was kept in every case, so no dependent's require line moved.
=build.rkt= (673) went to =src/build/build-plan.rkt= and was split at
step 6; =activate.rkt= (650) went to =src/install/activate.rkt= and was
split at step 7; =cli/main.rkt= (1525 lines) went to
=package-manager/src/entry/cli.rkt= and was split at step 8 into
=documents.rkt= and =dispatch.rkt= with the suite moved to
=package-manager/tests/entry/cli-test.rkt= (rows above). Counts: 20=20,
48=48, and the CLI suite plus the MCP suite at 167 checks, 0 failed, lints
0.

A partial split of =build.rkt= existed briefly -- six files -- and was
removed rather than committed. It was half a split: the new modules were
dead code and =build.rkt= had never been rewritten into a facade, so
nothing required them and the gate would have compiled files no one
called.

* What the restructure did
79 files moved through =git mv=, so history follows each file. 27 files
had relative requires rewritten: for every require the target was
resolved against the file's OLD directory, mapped through the table, and
recomputed from its NEW directory, then every rewritten require was
checked to point at a file that exists. 33 non-Racket files had path
references updated, longest-key-first so =read-check.rkt= is rewritten
before a bare =read-check.rkt= can match inside it.

Two passes were needed. The first missed BARE requires -- ="errors.rkt"=
without a =./= -- because its pattern demanded a prefix, and 38 files
contain literals like that. =raco make= caught it (spec.rkt:7 cannot open
module file). The second pass only rewrites a literal that is ALREADY
broken from its current directory, so it cannot damage one that works.

Three things the second pass correctly refused to guess at, rather than
silently rewriting: =holder.rkt= and =k-holder.rkt= are temp files the
tests CREATE with =build-path=, not modules, and =tools/repl.rkt= holds
repo-root-relative names passed to =path->complete-path=, which were fixed
by hand because they are not file-relative.

One real corruption was caused and found: the blind replacement rewrote
NAMING-REGISTER.org's OLD-path column as well as its new-path column, so a
row read =package-package-manager/src/entry/package-info.rkt=. Repaired.

  =rollback=, =remove= or =hold=, because README.md and =docs/API.org=

* The 17 red checks were fixed, 2026-10-17
- The suite was red BEFORE any of this work: 73 files, 939 checks, 17 failed.
  All 17 now pass, and the number of checks that RUN went up, because each bug
  had been hiding work behind it (apply.rkt 24 -> 84 checks, git-repo 23 -> 54).
- =with-mirror-lock= never called its thunk: a bare =thunk= where =(thunk)= was
  meant, so every clone, fetch and deepen taken under the lock returned a
  procedure and did nothing at all. One line, and it caused 11 of the 17.
- =raise-pm-error= was handed a hint string as a 4th POSITIONAL argument,
  because two adjacent string literals were meant to concatenate. They do not,
  in Racket. So "commit missing from mirror" crashed with an arity error
  instead of refusing, and it was unreachable until the thunk bug was fixed.
- Four tests walked up the wrong number of directories and landed on
  =package-manager/src= instead of the repo root, so their fixtures were
  missing; one still named =scripts/env.nu= after the restructure moved that
  file to =gate/env.nu=.
- One test spawned its lock holder with =(find-system-path 'exec-file)=, which
  answers with the bare word "racket" under proot. =process*= searches no PATH,
  so the holder never started and the test waited out its whole bound.

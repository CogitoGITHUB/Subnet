* What is not proved

  The Rust binary makes the document; the Racket side reads it.
- The gate's security stage still prints NOTHING-TO-CHECK. The security
  area exists and its rules are written, but no stage reads them yet.
- The editor side is not built. The join between the notation and the
  editor is A (the editor parses and renders on its own) or B (the editor
  asks the notation engine); both are written out in EDITOR-HANDOFF.org
  with the real numbers and NEITHER is chosen here.
- The inline emphasis and link keywords are not registered. The emphasis
  mark is drawn; a link is not checked.
- There are no test files in the tree. The verification runs live in /tmp
  as commands, because the root decision D-001 was lifted on 2026-10-19
  and the owner allowed one such run.

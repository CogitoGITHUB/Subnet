* What is not proved

- The Racket =check= command reads a parse tree document, not a .aiu page.
  The Rust binary makes that document; =nu tools/aiu.nu check= does both steps.
- A path that holds a space cannot be handed to racket as an argument, so
  every Racket command is run with a relative path from the project folder.
- The security rules have no caller yet: literate/targets.rkt and
  generation/write.rkt still raise their own refusals. The gate names this on
  every run.
- The =link= keyword is not registered, so a link inside a paragraph is not
  checked, and the =references= area holds no files.
- The kit — the MCP server, the skill and the plugin — is not built.
- The Racket side pays a module load of about 11 to 23 seconds on this phone.
  The checking work itself is fast; the engine side parses in 0 to 40
  milliseconds.

* The area
# what the area is and what it owes.
# The input area is Rust: the side that sees the bytes (rule 09, D-007).
# The keymaps stay in Racket, and this area never holds a key of its
# own — it answers the NAME of a key and the meaning side decides what
# that name means.
#
# The reader never uses a timer of its own. The kitty keyboard
# protocol's flags are what tell a key apart: the terminal is asked to
# report the escape codes it would otherwise swallow, so a key is never
# guessed at and a lone escape is the escape key.

* The area
# The join area is the only place the two languages meet (rule 09).
#
# On this phone the meaning side cannot be baked into a binary, so it runs
# as an external Racket process, and the hot path runs as an external Rust
# process. The wire between them is one line of JSON per message, and the
# numbers that forced this are in research/join-on-the-phone.org; the
# decision is D-008 in the root DECISIONS.org.
#
# The wire travels through two files, one for the request and one for the
# response, and that is a fact of this Racket build rather than a choice:
# racket/system hands a child process /dev/null for every stream that is
# not a file stream, so a child given a pipe is mute. The message shape is
# unchanged: one line of JSON each way.
#
# rust-exports.rs names every crossing between the two languages, one per
# crossing, so the seam is written down in one place.

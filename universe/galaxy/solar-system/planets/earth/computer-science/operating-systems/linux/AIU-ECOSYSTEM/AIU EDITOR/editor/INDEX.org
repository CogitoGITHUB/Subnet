* Files
# one line per file: its name, then the single job it performs. This index is updated in the same commit as any change here.

 - INDEX.org — this index: every file of the package and its one job
 - Cargo.toml — the crate manifest: the hot path builds from here
 - src/INDEX.org — the areas of the package, lowest first
 - src/errors/INDEX.org — the error area: the record, the raise, the render
 - src/errors/err.rkt — the error record: what happened, who, where
 - src/errors/raise.rkt — the one raise helper; nothing raises around it
 - src/errors/render.rkt — how an error prints: one shape, never a dump
 - src/narration/INDEX.org — the narration area: events, voice, wait, printer
 - src/narration/events.rkt — the event record: the schema, and the clock
 - src/narration/narration.rkt — a run's voice: open, step, note, warn, skip, decide
 - src/narration/wait-door.rkt — wait-for / wait-done; why is never blank
 - src/narration/print-console.rkt — the ONE printer to the terminal
 - src/machine/INDEX.org — the machine area: environment, locks, the door
 - src/machine/directories.rkt — the one place HOME and XDG are read
 - src/machine/locks.rkt — one-writer locks: wait and retry, never force
 - src/machine/cancel.rkt — the cancellation door every blocking call passes
 - src/join/INDEX.org — the join area: the wire, the meaning side, the hot path
 - src/join/protocol.rkt — the wire shape: one request and one response
 - src/join/transport.rkt — the transport: one request file, one answer file, one child
 - src/join/racket-entry.rkt — the meaning side's entry: one request in, one response out
 - src/join/load.rkt — where the meaning side is reached; the one call that asks it
 - src/join/hot-path.rkt — the call that asks the hot path; the other side of the seam
 - src/join/hot-path.rs — the Rust side of the seam: one request file in, one answer file out
 - src/join/wire-json.rs — the Rust side of the wire shape: read a request, write a response
 - src/join/rust-exports.rs — the functions the meaning side may call, one per crossing
 - src/journal/INDEX.org — the journal area: the record of every edit
 - src/journal/journal.rs — append every edit; replayable, in order
 - src/journal/replay.rkt — rebuild state after a crash; never guesses silently
 - src/buffer/INDEX.org — the buffer area: the text state
 - src/buffer/buffer.rs — the text: bytes, lines, offsets
 - src/commands/INDEX.org — the commands area: the command table
 - src/commands/commands.rkt — the command table: one name, one function
 - src/commands/tasks.rkt — the task table and the runner: declare, list, run, sequence
 - src/routes/INDEX.org — the routes area: the layers and the routing
 - src/routes/keymaps.rkt — the mapping tables, as data: the layers and their keys
 - src/routes/routes.rkt — the routing: which layer sees a key first
 - src/routes/keyboard.rkt — the keyboard: the bytes of a key become its name
 - src/input/INDEX.org — the input area: the bytes in, read in Rust
 - src/input/read.rs — read the bytes that arrive and say which key they are
 - src/input/keys.rs — the sequence parsing: what a key is, and its name
 - src/input/kitty.rs — the kitty keyboard protocol's opt-in flags, adopted not invented
 - src/dashboard/INDEX.org — the dashboard area: the pieces and their drawing
 - src/dashboard/dashboard.rkt — the meaning: what each piece shows, and the call that draws it
 - src/dashboard/pieces.rkt — the placeable piece list: the edges, the sizes, the order
 - src/dashboard/dashboard.rs — the drawing: the pieces are placed on a screen and the screen is written out
 - src/entry/INDEX.org — the entry area: argv, the dispatch, the session
 - src/entry/cli.rkt — argv to a command: one parser, one dispatch
 - src/entry/dispatch.rkt — the command table: one name, one function

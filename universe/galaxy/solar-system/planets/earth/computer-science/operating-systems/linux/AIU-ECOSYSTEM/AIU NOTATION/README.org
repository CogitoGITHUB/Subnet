* What it is
# the short answer, from HANDOFF.org and rule 12.
  - The owner's own file format and syntax in one: it replaces Org, Markdown
    and LaTeX for their everyday use.
  - Plain text is the source of truth; a rendering engine shows it live.
  - The product name is AIU-NOTATION. The program is separate and the code
    lives in one package directory, =notation/=.

* Principles
# one line each, from rules/rule-12-notation-syntax.org and HANDOFF.org.
  - Ordinary things use literal names, not symbols: a title is called title.
  - Plain lines with no name are a paragraph by default.
  - A named element is opened and closed with one tiny, consistent mark.
  - Links and other inline things use that same small enclosing mark.
  - Goal: insanely easy to read, insanely easy to type, instantly
    understandable by the owner and by agents alike.
  - The smallest slice first: title, paragraph, code block.
  - The editor helps typing, and live rendering hides the marks.
  - Only the hardcore parts (math, graphs) use advanced symbolic syntax:
    tier 3, far future.

* The mark
# decided by the owner; syntax/open-close-mark.org carries the detail.
  - Braces: { opens, } closes (notation D-014, owner, 2026-10-17).
  - A code block's body is opaque to the parser, so a { inside code never
    opens a notation element.
  - A code block closes by repeating its own word: the opening word alone
    on its own line. The editor hides that closer; the file keeps it.
  - Whether ordinary elements close the same way is still open; not decided.
  - The root =DECISIONS.org= record is pending; ROOT-REQUEST-D014.org holds
    the exact text to carry there.

* How it fits
# the seams, from plan/architecture.org.
  - The engine surface is called by the editor and the multiplexer, and
    calls nothing back into them.
  - The editor plugs in through the notation-engine boundary, in
    =../contract/=; it triggers the engine build and enters dev mode after.
  - Agents read a notation address carried inside the context bundle.
  - PM installs the notation, then bakes it in (rule 02); it is a package
    with its own kit, like every program.
  - The editor keeps its own features; notation carries none (rule 14).

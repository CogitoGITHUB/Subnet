#+TITLE: Goal — AIU NOTATION
# One job: what finished looks like for this program, in one paragraph, and how it is known to be met
# Status: filled 2026-10-16; plans stay general, not yet reviewed.

* The goal
# what finished looks like for this program, in one paragraph.
  One plain-text notation that replaces Org, Markdown and LaTeX for
  everyday work: ordinary things use literal names — title, paragraph,
  code block — opened with a tiny, consistent mark that never collides
  with prose or tags; plain lines are paragraphs, so everyday writing
  needs almost no syntax. The text is the source of truth: a context-free
  core with incremental reparse, so the editor renders it live and hides
  the marks while typing, and agents understand it without a manual.
  Literate code in the Org Babel sense is first-class — named chunks with
  targets, loaded in place or sent into other files — and the things the
  old tools did well travel under names: outlines, tags, properties,
  tables, planning states, links. The hardcore tier — math, graphs, the
  advanced symbolic syntax — is tier 3, planned far future.

* When it is met
# the observable signs, one per line. No dates.
  - A page opens with a title carrying its creation-time context; plain
    writing is paragraphs with almost no marks.
  - The editor renders the notation live and hides the marks; typing
    names is helped by completion and the keyboard layer.
  - Literate chunks with targets load and send code into other files;
    unchanged inputs SKIP by content hash.
  - Outlines, tags, properties, tables, planning states and links work
    as named, dispatchable elements.
  - Comments are first-class; rendering strips them.
  - The engine surface answers the editor through the contract boundary;
    incremental reparse and error recovery hold on partial text.
  - A send can name its notation address, and the addressing is stable.

* What it rejects
# directions this program refuses; the reasons live in non-goals.org.
  Symbols for ordinary things; a mark that collides with prose or tags; a
  format invented beyond need; the advanced tiers before the everyday one
  is proven.

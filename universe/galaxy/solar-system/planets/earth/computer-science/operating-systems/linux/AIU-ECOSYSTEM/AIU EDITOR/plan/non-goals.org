#+TITLE: Non-goals — AIU EDITOR
# One job: what this program will never do, and which tempting things are refused anyway
# Status: filled 2026-10-16; plans stay general, not yet reviewed.

* Deliberately not done
# one line per thing this program will never do, with the reason.
  - A daemon or background editor process — the phone kills processes;
    start is measured and instant (rule 01, WHEN-ON-LAPTOP).
  - A config that must load at startup — the baked binary is first-class
    without it (rule 02).
  - Notation knowledge in the loader — the editor is useful with the
    notation absent (rule 14).
  - A plugin runtime of its own — the extension surfaces are MCP and
    skills (research: plugin runtimes stay out).
  - Porting the old config wholesale — the map's verdicts: rebuild the
    machinery, keep the theme system, skip the application layer.
  - A mouse-required workflow — rule 13.

* Tempting but out
# things that look useful and are still refused, with the reason.
  - Adopting Helix or Neovim as the editor — Option A is the fallback,
    not the destination; our rules are not someone else's roadmap.
  - A second extension runtime via editor plugins — refused, same reason
    as the plugin system itself.
  - A desktop app, a web client, multiplayer editing, RAG inside the
    editor — surfaces and weight this phone does not need.
  - Keeping the old names and prefixes because they are familiar — the
    rebranding is part of the study's output, not an afterthought.

* What this project is
# One plain-text notation replacing Org, Markdown and LaTeX; product name AIU-NOTATION.
  - Ordinary things use literal names; the text is the source of truth; a rendering engine shows it live.
  - A page is a plain text file with the extension =.aiu=.
  - From Org: outlines, tags, properties, tables, planning states, links, literate code.
  - From LaTeX (tier 3, the most important): math and physics, units, figures, numbering, citations.

* Current state
# what is true right now, and what is proved.
  - The package is BUILT. The Rust crate compiles, the Racket areas load, the gate is green, and the feature table in =syntax/feature-status.org= holds one row per feature with the captured output as the evidence.
  - The three-line block form works: =<name> start=, the content on its own line(s), =<name> end=. The retired =end <name>= spelling is content.
  - The round trip is exact: a page prints back to the identical bytes, on CRLF pages, on multibyte UTF-8 pages and on a page with no trailing newline.
  - All five error names plus =bad-heading-level= are produced with a line, what the problem is and what to do about it.
  - The Racket model reads the parse tree document the Rust side writes, and the reader round-trips it.
  - The tables and JSON area is built: a table reads itself, checks each cell against its column type, draws as HTML and as LaTeX, and a document maps to JSON and back.
  - The heading keyword is in, with its computed numbering in both the Rust and the Racket half.
  - The security gate is a real check now: it probes every security rule and says so when a rule has no caller.

* What is not proved
# the honest gaps, so a fresh conversation does not guess.
  - The Racket =check= command reads a PARSE TREE DOCUMENT, not a =.aiu= page. The Rust binary makes that document; the daily script =tools/aiu.nu= does both steps for you.
  - Racket cannot open a module path that holds a space, so every Racket command must be run with a RELATIVE path from this directory. The gate and the daily script already do this.
  - The security rules have NO caller yet: =literate/targets.rkt= and =generation/write.rkt= still raise their own refusals instead of calling =security/refuse.rkt=. The gate names this on every run.
  - The =link= keyword and the inline emphasis are not registered. The emphasis mark is drawn; the link is not.
  - The kit (the MCP server, the skill and the plugin) is not built.
  - The comment lint had 54 real violations on 2026-10-19 and the work to fix them lands with the same change.
